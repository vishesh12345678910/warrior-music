Where do I find this address?

If running locally, start the server on your PC with node server.js. Type your computer's local IP address (e.g. 192.168.1.9:3000). If hosted online (Vercel, Render, Hostinger), type your website URL.

Auto-discovery works when both phone and PC are on the same Wi‑Fi network.
